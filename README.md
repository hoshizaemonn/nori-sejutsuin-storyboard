## 3本の役割

| 動画 | 表現 | 目的 |
|---|---|---|
| 01 | 実写風AI・店舗紹介 | 先生の人柄と相談しやすさを伝える |
| 02 | アニメ・店舗紹介 | 日常の気がかりから相談の流れを描く |
| 03 | フルAIアニメ・学びの入口 | 自分・家族の健康や学びへの関心を相談につなげる |

各30秒・16:9は提案値です。動画本編は未制作で、現在は静止画による確認段階です。

## 確認したいこと

- 3本の役割と構成、字幕・ナレーションの言い回し
- 先生の見た目と院内の再現、施術姿勢・説明内容
- 電話番号・予約導線・学びの受付範囲
- 掲載先と尺、画面比率

修正メモは「動画01／シーン03」のように動画番号とシーン番号を添えてください。GitHubのIssuesにまとめられます。

## 画像について

画像は内蔵画像生成機能によるAIモックアップです。01・02の院内はGoogle掲載写真を参照し、畳・海の壁掛け・ベッド・障子などを反映しています。人物の動作・別角度・配置の細部は演出案で、実写の撮影記録ではありません。03の学習風景は架空のイメージです。
